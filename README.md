# HotMoney A股拉升前特征研究模块

当前仓库原先只有 LICENSE，因此本次是从零建立可运行的研究 MVP，并非在既有业务代码上做增量修改。

## 功能

- 使用 AKShare 获取当前 A 股股票列表、日线行情和历史龙虎榜汇总。
- 计算过去 1/3/5/10 日收益、成交额/成交量相对 5 日均值、波动率、均线偏离。
- 用明确的研究标签定义事件：未来 3 个交易日收盘价相对当前收盘价上涨至少 15%。
- 对事件日前 1–5 个交易日生成回溯样本，便于比较其共同特征。
- 对配置的营业部名称做龙虎榜席位匹配，并保存匹配证据。
- 输出 CSV 和 JSON，便于后续做统计检验、基线模型和滚动回测。

## 安装

```bash
python -m pip install -r requirements.txt
```

## 运行

先小范围验证数据源和字段：

```bash
python hotmoney_analyzer.py --limit 10 --start 2024-10-20 --end 2026-10-20 --output data
```

指定股票：

```bash
python hotmoney_analyzer.py --symbols 600519,000001 --start 2024-10-20 --end 2026-10-20
```

不传 `--limit` 或 `--symbols` 会处理当前股票列表中的全部股票，耗时较长；建议先小范围运行并确认 AKShare 数据源稳定。

## 输出

- `data/daily_features.csv`：每日行情及技术特征
- `data/lhb_events.csv`：龙虎榜事件
- `data/youzi_seat_matches.csv`：营业部名称匹配证据
- `data/rally_events.csv`：符合事件定义的样本
- `data/pre_rally_samples.csv`：事件前 1–5 日的回溯样本
- `data/analysis_summary.json`：样本数量与特征均值对照
- `data/cache/`：行情和龙虎榜缓存

## 重要边界

- 这是历史研究和特征探索工具，不是自动荐股或买卖系统。
- “未来 3 日涨幅 >= 15%”是可调整的事件定义，不等同于真实游资拉升的因果证明。
- `pre_rally_1_5d` 是使用未来行情构造的标签，只能作为训练目标，不能作为当日可用特征，否则会产生数据泄漏。
- 当前股票列表可能漏掉已退市股票；两年历史覆盖并不等于完整幸存者无偏样本。
- 龙虎榜出现营业部及名称相似匹配，不能证明实际交易者身份或单独导致股价上涨。
- AKShare 上游接口及字段可能变化。运行后必须检查日志、输出行数和字段；尚未在真实联网行情环境完成端到端验证。
- 在做模型前应先加入无拉升/失败拉升对照样本、时间序列滚动验证、交易费用/滑点/涨跌停无法成交与 A 股 T+1 约束。
